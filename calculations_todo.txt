1. ∑ HP (сумма HP охраны)
======================================================================
Где используется:
  - Лист "Банки" колонка "∑ HP"
  - Лист "События и Ящики Пандоры" колонка "∑ HP"
  - Лист "Тюрьмы" колонка "∑ HP"
  - Лист "Герои" колонка "∑ HP"
  - Лист "Города" колонка "∑ HP"
  - Лист "Все Арты" колонка "Охрана" (текст, не сумма)
  - Лист "Все Заклы" колонка "Охрана"
  - Лист "Все Навыки" колонка "Охрана"
  - Лист "Опыт" колонка "∑ HP"

Формула (MainForm.cs, тысячи мест, например строки 6413, 6438, 6478):
  ∑ HP = Σ (monster_HP[guard[i].monster_id] × guard[i].count)

Где monster_HP берётся из TblMonsters.Columns["HP"] (заполняется
CreateTblMonster, MainForm.cs:11042).

Причина не считаем:
  - Требует полной таблицы monster_HP (145 записей), которая сейчас
    не извлечена в наш localizer.py.

2. ∑ XP (суммарный опыт)
======================================================================
Где используется:
  - Лист "Опыт" колонка "∑ XP"

Формула (MainForm.cs, GetPercent / AllExperience aggregator):
  Для сундуков: XP = HP (= experience field)
  Для монстров: XP = monster_HP × count (см. конкретные строки 6437-6440)
  Для банков:   XP = guard_HP_total (сумма HP охраны банка)
  Для учёных:   XP = 1000 (константа? уточнить по MainForm.cs)
  Для Learning Stone: XP = 1000 (зафиксировано в SaveLearningStone, MainForm.cs:9699)

Причина не считаем:
  - Зависит от ∑ HP (см. п.1)
  - Также требует уточнения формулы для каждого типа объекта (учёные, банки)

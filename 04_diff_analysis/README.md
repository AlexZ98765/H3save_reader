# 04_diff_analysis — Differential Analysis Scripts

Эта папка содержит **исторические разовые скрипты**, использовавшиеся
для ручного локализования полей формата `.GM1`. Они НЕ вызываются в
runtime — это исследовательский архив.

## Структура

```
04_diff_analysis/
├── README.md                         (этот файл)
├── build_object_type_dictionary.py   ⭐ универсальный — парсит LazyLlama wiki
│                                     (не привязан к карте; остаётся здесь)
└── <MapName>/                        подпапка для каждой конкретной карты
    ├── README.md                     описание скриптов для этой карты
    ├── analyze_*.py                  скрипты дифференциального анализа
    ├── build_*.py                    скрипты построения mapping-ов
    ├── find_*.py                     скрипты поиска (header pointers, и т.д.)
    ├── verify_*.py                   верификация маппинга
    ├── regenerate_*.py               вспомогательные генераторы
    └── *.json / *.md                 отчёты дифф-анализов
```

## Когда создавать новую подпапку

При добавлении новой карты для тестирования (например, `examples/MyNewMap/`)
— создай подпапку `04_diff_analysis/MyNewMap/` и клади туда новые
дифф-скрипты. Это сохраняет чистую структуру и явно показывает, какие
скрипты привязаны к какой карте.

## Универсальные скрипты (остаются на верхнем уровне)

| Скрипт | Назначение |
|--------|------------|
| `build_object_type_dictionary.py` | Парсит HTML-страницу LazyLlama wiki (`Map_Editor_Objects`) и строит `03_object_mapping/object_types_dictionary.json` (2037 типов объектов). Не привязан к конкретной карте. |

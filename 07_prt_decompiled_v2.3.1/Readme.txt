Специально для off-line турниров по Heroes of Might and Magic III на HeroesPortal.net


ProspectorRT 2.3 - Анализ СТАРТОВЫХ сейвов HoMM3

Редакции:
1. ProspectorRT - SoD Edition (RoE, AB, SoD, Heroes Chronicles)
2. ProspectorRT HE - HotA Edition (HotA v.1.3.x, v.1.4.x)
3. ProspectorRT WE - WoG Edition (WoG, Era II)


Основное назначение:
Сократить время на разведку и хоть как-то автоматизировать этот процесс.


Начало работы:
 1. Открываем СТАРТОВЫЙ сейв - пункт меню "Файл". 
    В заголовке окна появляются имя файла, размер карты и ее название.

    Всплывающая подсказка пункта меню покажет полный путь до сейва.

 2. Стартуем анализ - пункт меню "Старт".
    Прервать этот процесс можно в любой момент - пункт меню "Стоп".
    Анализ сейва будет стартовать автоматически, если снять "галочку" пункта меню
    "Сервис -> Настройка -> Кнопка Старт".
 3. Повторный анализ - пункт меню "Обновить".
    Нужен, например, в том случае, если Вы ищете нужный расклад.
 4. Пункт меню "Сервис" -> "Экспорт в Excel" - позволяет экспортировать содержимое
    выбранных таблиц в файл формата Excel 2007/2010 с расширением XLSX , где каждая
    таблица будет представлена на отдельном листе.
 5. Пункт меню "Сервис -> Оракул -> Версия" - позволяет выбрать верcию HoMM3,
    необходимо для построения дерева навыков.
 6. Пункт меню "Сервис -> Оракул -> Максимум уровней" - задает количество уровней
    дерева навыков, максимум - 20.

    Внимание:    
    На уровнях больше 15-того слишком большие вычисления и расход оперативной
    памяти, поэтому рекомендуется использовать только по необходимости. 

 7. Пункт меню "Сервис -> Оракул -> Без запуска игры" - с установленной "галочкой"
    расчет дерева навыков будет производится без необходимости запуска игры, со
    снятой "галочкой" - требуется игру запустить и выбрать тот же сейв, что загружен
    в ProspectorRT.
 8. Пункт меню "Сервис -> Настройка -> Кнопка Старт" - со снятой "галочкой" анализ
    сейва начнется сразу после открытия, а с установленной для начала анализа необходимо
    нажать кнопку "Старт".
 9. Пункт меню "Сервис -> Настройка -> Последних открытых файлов" - задает количество
    последних открытых файлов в списке меню "Файл". По умолчанию - 8.
10. Пункт меню "Сервис -> Настройка -> Названия объектов" открывает форму с возможностью
    изменять названия всех объектов в зависимости от выбранной версии или подгружать их
    из файла. Подробности см. ниже.
11. Пункт меню "Справка" - открывает этот файл.

Форма "Названия объектов:
Позволяет изменять названия всех объектов в зависимости от выбранной версии или
подгружать их из файла.
1. Менять названия объектов можно в любой момент. Если сейв загружен, то результаты
   анализа будут обновлены автоматически.

2. Соответствие версий:
   а. "The Shadow of Death" - английская версия
   б. "Дыхание Смерти" - русская версия
   в. "Полное Собрание" - русская версия
   г. "По умолчанию" - русская версия "WoG 3.58f"

3. Если выбран пункт "Из файла", то необходимо указать файл с названиями объектов
   нажав кнопку "...". 
   В дистрибутиве программы в папке "Data" находятся четыре файла с названиями.
   Соответсвие версий имени файла:
   а. Complete.txt - "Полное Собрание" русская версия
   б. SoD_En.txt - "Дыхание Смерти" английская версия
   в. SoD_Ru.txt - "Дыхание Смерти" русская версия
   г. WoG_Ru.txt - "WoG 3.58f" русская версия

   Эти файлы в программе не используются и выложены в качестве примеров формата
   файла.

   Если в таблицах вместо названий абракадабра, то можно попробовать выбрать другое
   значение в выпадающем списке "Кодировка".

4. Требования к формату файла с названиями объектов:
   а. Названия секций должны быть в квадратных скобках и полностью соответствовать
      названию секций в файлах-примерах.
      Последовательность секций значения не имеет. Если секция отсутствует, то будет
      использовано значение по умолчанию.
   б. Порядковый номер элемента секции и его название должны быть отделены пробелом.
   в. Количество элементов в секции должно быть точно таким же как в файлах-примерах.
      Если элементов в секции будет меньше, то будут использованы значения по умолчанию
      для всей секции.
 

Работа с таблицами:
Каждая таблица имеет несколько локальных меню, вызываемых по правой кнопке мыши.
1. Локальное меню в области строк:
   а. "Копировать" - копирует в буфер обмена выделенные строки таблицы вместе с
       названиями столбцов.
   б. "Копировать ячейку" - копирует в буфер обмена содержимое выделенной ячейки.
   в. "Общие итоги" - показывает/скрывает строку итогов таблицы.
   г. "Итоги по группам" - показывает/скрывает строку итогов групп.
       Имеет смысл, если есть группировки.
   д. "Объединить ячейки" - объединяет ячейки с одинаковыми значения.
       Специфическая функция, но иногда бывает полезной.
   е. "Автоширина столбцов" - пытается уместить все видимые столбцы без
       горизонтальной полосы прокрутки. Если отключена, то горизонтальная полоса
       прокрутки появляется.
   ж. "Шрифт" - позволяет выбрать нужный шрифт таблицы.
   з. "Печать" - позволяет распечатать таблицу либо экспортировать ее содержимое
       в любом из популярных форматов (PDF, XLS, XLSX, HTML, RTF, TEXT и т.д.)
   и. "Настройки" - группа функций работающих с шаблонами (макетами) таблицы.
       а. "Восстановить шаблон" - восстанавливает внешний вид таблицы.
           Если есть "шаблон по умолчанию", то по нему, если нет, то по стартовому. 
       б. "Создать шаблон по умолчанию" - создает шаблон, используемый на старте
           программы и при восстановлении. После создания его можно удалить.
       в. "Сохранить шаблон" - сохраняет настроенный внешний вид таблицы в файл
           в формате XML.
       г. "Загрузить шаблон" загружает ранее сохраненные шаблоны.
   к. "Показать ячейку" - показывает содержимое ячейки в отдельном окне в
       таблицах "События и Ящики Пандоры", а так же "Герои" и "Тюрьмы".
   л. "Экспорт в LMOracle" - в таблице "Герои" экспортирует выбранных Героев в
       LM Oracle H3.
       а. "Копировать" - через буфер обмена. В LMOracle - "Add Heroes -> Clipboard"
       б. "Сохранить" - через файл. В LMOracle - "File -> Open..."
   м. "Дерево прокачки" - в таблице "Герои" показывает дерево навыков выбранного
       Героя, работает так же по  двойному клику.
       В окне с деревом навыков в локальном меню два пункта  "Развернуть все" и
       "Свернуть все". Так же работает инкрементальный поиск, а для перемещения
       по подсвеченным веткам дерева клавиши "Ctrl+стрелка вверх" и "Ctrl+стрелка
       вниз". Инкрементальный поиск работает только на развернутых ветках дерева.

       При снятой галочке пункта меню "Сервис -> Оракул -> Без запуска игры" для
       правильного расчета дерева навыков необходимо запустить игру и выбрать тот
       же сейв, что загружен в ProspectorRT.

2. Локальное меню в области заголовков столбцов:
   Представлено пятью функциональными группами:
   а. Функции сортировки
   б. Функции группировки
   в. Функции управления столбцами
   г. Функции фильтра
   д. Функция управления типами фильтра столбца

3. Локальное меню в области общих итогов.
   Доступно при включенном пункте меню "Общие итоги".
   Позволяет управлять функциями агрегации.

4. Локальное меню в области итогов групп.
   Доступно при наличии группировки и включенном пункте меню "Итоги по группам".
   Позволяет управлять функциями агрегации, но только по группам.

5. Локальное меню в области группировки.
   Доступно при выборе пункта меню "Показать область группировки".
   Позволяет управлять группами.

В дополнение к локальным меню:
1. Меню фильтра столбца.
   Становится доступным при клике левой кнопкой мыши на пиктограмму, которая
   появляется при наведении указателя мыши на заголовок столбца в правом
   верхнем углу.
   Имеет два типа списка - обычный список уникальных элементов столбца и список
   с возможностью помечать флажками отдельные его элементы. Тип списка задает
   пункт "Фильтр с помечаемым списком" в локальном меню в области заголовков столбцов.

2. Сортировка по столбцу - клик левой кнопки мыши на заголовке столбца.
   а. Повторный клик сменит направление сортировки.
   б. С нажатой клавишей Shift:
      а. Добавит столбец к набору столбцов по которым отсортирована таблица
      б. Сменит направление сортировки у столбца в наборе
   в. С нажатой клавишей Ctrl:
      а. Исключит столбец из набора
      б. Отменит сортировку, если столбец один

3. Инкрементальный поиск.
   Используется для поиска по первым буквам или цифрам.

4. Всплывающая подсказка.
   Показывает содержимое ячейки не умещающееся в поле таблицы. Если в конце
   всплывающей подсказки есть многоточие, то содержимое ячейки показано НЕ
   полностью.
